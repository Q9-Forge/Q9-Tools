# Qpaths

Erste Q9-Portierungsbasis für die Pfad-/Geräteinspektion. Für jeden
angegebenen Pfad werden Pfad-ID, Gerät, aktuelle Position und Dateigröße über
die OS-9-GetStat-Aufrufe ausgegeben. Die vollständige systemweite
Prozess-/Pfadtabelle des Originalprogramms benötigt noch den Kernel-DB-Aufruf.
