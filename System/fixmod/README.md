# Qfixmod

Konservative erste Portierungsbasis des OS-9-Modulheader-Editors. Unterstützt
die CRC-/Header-Aktualisierung sowie Revision, Edition, Zugriffsrechte und
Stackfeld eines Moduls. Änderungen werden direkt in der angegebenen Datei
geschrieben; deshalb zuerst mit einer Kopie testen. STB-Synchronisierung und
Owner-Parsing (`-uo`) folgen separat.
